ZIP을 전부 압축 해제하세요.

서버·백엔드 업데이트: Docker Desktop 실행 → Update-Server.cmd 더블클릭
내 클라이언트: Minecraft 종료 → Update-Client.cmd 더블클릭
.cmd 파일은 각각 PowerShell(.ps1)을 실행하며 마지막에 창을 남깁니다.
서버 업데이트는 저장 종료·백업 후 설치와 재시작을 수행하므로 서버 이용자가 나간 뒤 실행하세요.
기존 .env·연결 토큰·정책 설정을 보존합니다. 백업은 /srv/mc/backups 아래에 생성됩니다.

친구: 기존 namanseulfarming JAR만 제거하고 namanseulfarming-1.1.1.jar를 mods에 넣으세요.
모든 클라이언트와 서버가 같은 새 모드 파일을 써야 합니다 (연결 프로토콜 13).
모드팩 전체 ZIP은 CurseForge 가져오기용입니다.

OP 2 이상: /경제관리. OP가 아니면 허브의 경제 관리 버튼은 보이지 않습니다.
위쪽 분류와 왼쪽 기능을 클릭해서 바로 이동합니다. 목록과 입력란은 휠 또는 페이지 버튼으로 이동합니다.
신규 보상·납품·프로젝트·이벤트 ID는 비워 두면 자동 생성됩니다.
기존 ID는 돋보기로 검색 → 행 선택 → 선택 확인. 신규 버튼은 기존 ID를 지웁니다.
시각·대상 플레이어·UUID를 확인할 수 있고 긴 ID·항목명은 마우스를 올려 확인합니다.

수정 내역은 UI_IMPROVEMENTS_1.1.1.md에 있습니다.
자동 검증: 백엔드 테스트 51개, Java 보호·표시 시험 7종, 모드 Java 컴파일·JAR 생성 통과. 운영 의존성 취약점 0개.
실제 Minecraft 화면 클릭·OP 전환·해상도별 표시·사용자 Docker 설치 실행은 이 환경에서 검증하지 않았습니다.
ADMIN_TEST_CHECKLIST.md의 실제 게임 항목으로 확인하세요.

아이템 이름·아이템 ID·UUID는 일괄 번역하지 않습니다. 공개 플레이어 간 거래소 구매·정산은 이번 UI 개선과 별도 미구현 기능입니다.
