경제 관리 업데이트 1.1.0 — Minecraft 1.21.1 / NeoForge 21.1.244

서버와 모든 클라이언트에 같은 JAR를 설치해야 합니다.

서버 업데이트(기존 mc-ubuntu 컨테이너):
1. 이 ZIP을 Windows 폴더에 전부 압축 해제합니다.
2. 해당 폴더에서 PowerShell을 엽니다.
3. powershell -ExecutionPolicy Bypass -File .\Update-Server.ps1

스크립트는 현재 Minecraft와 백엔드를 저장 종료하고, 기존 DB·백엔드·원본 모드·플레이어 데이터를 /srv/mc/backups 아래에 백업합니다. 기존 .env·연결 토큰·정책 설정은 보존합니다. 업데이트 설치와 스키마 023 적용 뒤 백엔드와 Minecraft를 시작합니다. 사용자 환경에서 이 스크립트를 직접 실행해 검증한 것은 아닙니다. 실패하면 출력된 단계와 백업 경로를 확인하세요.
서버 시작 확인: docker exec mc-ubuntu tail -n 30 /srv/mc/server/admin-update-launch.log

내 클라이언트 업데이트:
Minecraft를 종료하고 같은 폴더에서
powershell -ExecutionPolicy Bypass -File .\Update-Client.ps1
기본 대상: 사용자 폴더\curseforge\minecraft\Instances\Lime Colony Economy\mods
다른 경로는 -ModsPath '실제 mods 경로'를 붙입니다.

친구: 기존 namanseulfarming JAR를 제거하고 namanseulfarming-1.1.0.jar를 mods에 넣으세요. 새 모드팩 전체 ZIP은 CurseForge에서 가져오기용입니다.

게임: 한국어 언어 선택 → OP 2 이상으로 /경제관리 (또는 /economyadmin). 돈 지급은 지갑 분류, 아이템 복구는 우편 분류에서 처리합니다. /hub에도 경제 관리 버튼이 있습니다. 일반 플레이어는 관리자 권한 검사를 통과하지 못합니다.

상품 등록: 인벤토리에서 선택 → 수량·개당 가격 입력. 상품 아이콘과 긴 이름 툴팁을 표시합니다. 아이템 이름을 새로 번역하지 않았습니다.

검증: Node 자동 테스트 46개, Java 거래 보호 시험, 모드 빌드 통과. 운영 의존성 취약점 0개. 실제 게임 접속·화면 클릭·업데이트 스크립트 실행은 사용 환경에서 확인해야 합니다.

자세한 관리 기능과 복구 범위는 ADMIN_ECONOMY_1.1.0.md, 실제 테스트 목록은 ADMIN_TEST_CHECKLIST.md에 있습니다. 공개 플레이어 간 거래소 구매·정산은 아직 별도 미구현 기능입니다.
