# 1.1.1 관리자 UI 개선

기존 모드 이름 Namanseul Farming, 모드 ID namanseulfarming, 모드팩 이름 Lime Colony Economy를 유지합니다. 서버·클라이언트·백엔드 버전은 1.1.1입니다. 서버와 모든 클라이언트를 함께 업데이트해야 합니다(연결 프로토콜 13).

- 보상·납품 정책 신규 ID는 비워 두면 서버가 자동 생성합니다. 보상은 기존 규격인 대문자 16자리 16진수, 납품 정책은 고유 정책 문자열을 사용합니다. 프로젝트·이벤트도 신규 ID 자동 생성을 유지합니다.
- 기존 항목을 수정·취소·초기화할 때는 ID 입력란 옆 돋보기로 검색해서 선택합니다. `신규` 버튼은 선택된 ID를 지워 새 항목으로 등록할 수 있게 합니다. 생성된 ID는 저장 성공 후 입력란에 표시됩니다.
- 검색 창은 등록·발생 시각, 대상 플레이어, ID/UUID를 표로 보여줍니다. 닉네임·UUID·항목 이름 검색, 번호 페이지, 휠 이동, 행 선택 후 `선택 확인`을 지원합니다. 전체 ID·항목 이름은 행에 마우스를 올려 확인합니다. 공동 프로젝트·이벤트는 개인 소유자가 없어 서버 공통 항목으로 표시합니다. 시각은 클라이언트의 현지 시간 기준입니다.
- 플레이어, 보상 정책, 납품 정책, 수락 의뢰, 미수령 우편, 프로젝트, 이벤트, 미환불 구매 기록 검색을 제공합니다. 원본 작업에 대한 권한을 먼저 검사하며 임의의 테이블이나 필드를 요청할 수 없습니다.
- 분류를 화면 위에 모두 표시하고, 기능 선택·조회 결과·입력을 나란히 배치합니다. 메뉴·목록·입력 페이지와 휠 이동, 긴 제목 툴팁을 제공합니다. 변경 전 확인 화면도 페이지로 전체 값을 검토합니다.
- 상점·우편·현황·납품·프로젝트·허브의 기본 화면 크기를 줄였습니다. 프로젝트 목록에 페이지 표시와 휠 이동을 넣었습니다.
- OP 2 미만에게는 허브의 관리 버튼을 숨깁니다. 권한을 해제하면 열린 허브의 버튼도 제거됩니다. 서버 OP 검사와 백엔드 관리자별 권한 검사는 유지합니다.
- 영문으로 남아 있던 우편 상세·보상·프로젝트 진행도, 상태 값, 관리자 작업 이름, 가격 효과 종류, 연결·검증 오류 및 모드 설정 문구를 한글로 정리했습니다. 아이템 이름·아이템 ID·UUID·사용자가 작성한 제목과 내용은 일괄 번역하지 않습니다.
- 관리자 권한 입력에서 `지갑, 상점` 같은 한글 분류명도 사용할 수 있습니다. 저장되는 권한 값은 기존 API 규격을 유지합니다.

검증: 백엔드 자동 테스트 및 Java 보호·표시 시험, 실제 NeoForge 의존성을 사용한 Java 컴파일/JAR 생성. Minecraft 화면의 실제 클릭·OP 전환·해상도별 화면 검증은 운영 환경 체크리스트에 남겨 두었습니다.

DB 스키마 변경은 없습니다. 기존 업데이트 스크립트가 .env·연결 토큰·기존 정책을 보존하고 백업 후 설치합니다. ZIP의 Update-Server.cmd, Update-Client.cmd를 더블클릭하면 됩니다. 실패 메시지가 사라지지 않도록 실행 창을 남깁니다.
