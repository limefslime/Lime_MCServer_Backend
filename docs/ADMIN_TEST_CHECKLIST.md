# 관리자 경제 1.1.0 검증

자동 검증: Node 경제 테스트 46개, Java 거래 프로토콜·인벤토리 계획·등록 영수증·감사 기록·의뢰·우편 시험, NeoForge 모드 컴파일, 의존성 감사.

## 실제 서버에서 확인할 항목

- [ ] 서버와 모든 클라이언트에 1.1.0 JAR가 한 개씩만 설치되고 프로토콜 12로 접속된다.
- [ ] OP 2는 `/경제관리`를 열고, 일반 플레이어는 거절된다.
- [ ] 닉네임/UUID 조회, 입력 페이지·목록 페이지 이동, 작은 GUI 배율에서도 버튼이 보인다.
- [ ] 100원 지급 후 응답 중단·재접속·원래 요청 재시도에도 한 번만 지급된다.
- [ ] 잔액 직접 설정 시 조회 후 잔액이 바뀌었으면 거절된다.
- [ ] 상품 구매·판매 가격·재고·재입고 설정이 실제 거래에 반영된다.
- [ ] 가격 0·음수·판매가>구매가·수량 소수·초과 수량이 거절된다.
- [ ] 인벤토리 등록에서 가격·수량 입력, 아이콘·긴 이름 줄임 표시·툴팁을 확인한다.
- [ ] 등록 취소 시 원본 이름·인챈트·구성요소가 유지된다.
- [ ] 복구 우편 수령, 응답 중단, 인벤토리 부족, 재접속 후 원본 아이템이 정확히 한 번 지급된다.
- [ ] 의뢰 정책 변경이 수락한 기존 조건을 바꾸지 않고, 취소 시 납품 수량을 우편으로 돌려준다.
- [ ] 기여금 차감, 프로젝트 완료 보상, 환불이 중복 처리되지 않는다.
- [ ] 준비 이벤트가 거래 가격에 적용되지 않고 활성 이벤트만 적용된다.
- [ ] 집중 구역 해제·선택, 경험치 설정, 지갑 이용 정지·경제 점검을 확인한다.
- [ ] 구매 환불 영수증을 다른 요청으로 재사용해도 중복 환불되지 않는다.
- [ ] 관리자 권한 제한·작업 사유·원장·지속 감사 파일을 확인한다.
- [ ] 한국어 메뉴에서 아이템 이름 자체가 새 번역으로 바뀌지 않는다.

자동 테스트는 위 게임 실행 확인을 대체하지 않는다. 공개 플레이어 간 거래소 정산은 별도 미구현 기능이다.

## 1.1.1 추가 게임 검증 (실제 게임에서 확인 필요)
- [ ] OP가 아닌 플레이어에게 경제 관리 버튼이 보이지 않고 /경제관리 명령이 거절된다.
- [ ] 허브가 열린 상태에서 OP를 해제하면 관리 버튼이 사라지고, OP 2 이상으로 복원하면 나타난다.
- [ ] 보상·납품 신규 ID를 비워 저장하면 고유 ID가 생성되고 입력란에 표시된다.
- [ ] 같은 요청을 재시도해도 새 정책이 중복 생성되지 않는다.
- [ ] 기존 정책은 돋보기 선택 후 수정하고, 신규 버튼은 선택된 ID만 지운다.
- [ ] 플레이어·우편·의뢰·프로젝트·이벤트·구매 내역의 돋보기 검색이 해당 분류만 표시한다.
- [ ] 검색 표의 시각·닉네임·UUID가 맞고, 선택 후 확인하면 원래 입력란에 정확한 ID가 들어간다.
- [ ] 돋보기 검색 취소 시 원래 값과 다른 입력값이 유지된다.
- [ ] 검색어·번호 페이지·휠 이동이 작동하고, 마지막 페이지의 다음 버튼은 비활성이다.
- [ ] 원본 구매를 이미 환불하면 해당 구매는 환불 검색 목록에서 빠진다.
- [ ] 모든 분류가 화면 위에 보이고, 기능 선택은 순환 버튼 없이 직접 가능하다.
- [ ] 입력 페이지를 넘겼다가 돌아와도 작성한 값이 유지된다.
- [ ] 긴 제목·아이템 이름·UUID는 마우스를 올려 전체 값을 확인한다.
- [ ] GUI 배율 2·3·4 및 작은 창에서 버튼·페이지·입력칸이 겹치지 않는다.
- [ ] 변경 확인 화면에서 모든 입력값을 페이지로 검토할 수 있다.
- [ ] 우편 상세·보상 상태·프로젝트 효과·오류 메시지가 한글로 표시된다.
- [ ] 아이템 이름과 등록 ID, 사용자가 작성한 제목·내용은 원래 값을 유지한다.
